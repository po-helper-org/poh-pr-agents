# Большой дифф рвал LLM по таймауту — ревью сделано map-reduce за флагом

## Ситуация

На больших PR один проход LLM упирался в таймаут (`litellm.Timeout 90→271.79с` на `/review`) и деградировал по качеству. Ретраи были захардкожены upstream, а вложенность таймаутов инвертирована — «осиротевшее» дожигание бюджета провайдера после обрыва.

## Причина

Архитектура одиночного прохода не масштабируется по размеру диффа: один вызов LLM должен проглотить весь PR целиком, и чем больше PR, тем ближе к таймауту и тем хуже качество. Ретраи upstream не настраивались, и каждый обрыв уходил в повтор полного прохода по самой дорогой модели.

## Решение

Эпик APRP — адаптивная обработка PR по размеру диффа (спецификация оформлена 6-стадийным pipeline: context→problem→concept→debate→draft→validate). Два прод-эффекта разделены в мерже:

- **Фикс вложенности таймаутов, не за флагом** — чистая вложенность таймаутов `ai<attempt<task<visibility` (чинит инцидент 90→271с сразу);
- **map-reduce, за флагом `RELIABILITY_MAPREDUCE` (OFF по умолчанию)** — классификатор размера (контекстное окно модели + бюджет таймаута), план чанков с приоритизацией (core>tests>config>docs, исключение generated/vendored), fast-ack с ETA, ревью чанка прямым вызовом LLM, reduce-синтез с явным «не отревьюено» при частичном сбое, fan-in job-стор с CAS-барьером reduce, тиринг моделей (cheap/deep), eval-харнесс по посевным багам (recall/false-positive).

Всё аддитивно, stdlib-only, 236 unittest (было 82), включая e2e map-reduce и регресс на кросс-процессную гонку очереди.

## Как проверить

```
cd self-hosted && python3 -m unittest discover -s reliability/tests -t . -v
```

236 тестов зелёные. Map-reduce на стейджинге: `RELIABILITY_MAPREDUCE=1` + `DEEP_MODEL=<deep-модель>` → открыть большой PR → fast-ack/прогресс/итог → `reliability/eval/run_eval.py --live` для базового качества.

## Уроки

- Опасные фичи едут за флагом OFF: фикс таймаутов включился сразу, а map-reduce не менял прод-путь одиночного прохода до осознанного включения на стейджинге.
- Нагрузочный тест ядра вскрыл кросс-процессную гонку атомарного захвата между репликами worker'а — регресс-тест на неё теперь есть.
